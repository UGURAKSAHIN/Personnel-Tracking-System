FAQ

Common questions before you publish or pitch the product.

Does this product need a backend?

No for the public demo. This repo now also includes an optional backend for server-side data sync and secure Stripe checkout when you want a full-stack deployment.

Can I customize the branding and copy?

Yes. The landing copy, visual system, product name, pricing, and packaging language can all be adapted for your own brand.

Can visitors safely test the demo?

Yes. The current setup is local-first, so edits stay in the visitor's browser unless they export the data themselves.

How do I deliver it after a sale?

Use the buyer bundle workflow already included in the repo, keep the public demo online, and send the packaged source separately.
